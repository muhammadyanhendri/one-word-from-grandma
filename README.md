A make.fun entry for "One Word From Grandma": the program writes exactly one word to `entry.txt` in the output directory — the single word a grandma would text about AI. The word is **DEARROBOT**: she opens every message like a letter, even to a robot, so the greeting and the addressee run together into one word, capitals and all. Warm, a little baffled, and unmistakably about a robot.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
